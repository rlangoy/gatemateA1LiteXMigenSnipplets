# mycsrlib Installation Notes

## Overview

`mycsrlib` provides a LiteX CSR peripheral (`CRC32Peripheral`) that wraps a
VHDL CRC32 entity (`hdl/crc.vhdl`).  Because standard Yosys has no `read_vhdl`
command, the GHDL Yosys plugin is required.  A custom toolchain subclass
(`GhdlCologneChipToolchain`) patches the Yosys script at build time to load
the plugin and translate `read_vhdl` calls into `ghdl` commands.

## Prerequisites

| Tool   | Version tested | Notes                         |
|--------|---------------|-------------------------------|
| Yosys  | 0.63          | With plugin support enabled   |
| GHDL   | 5.0.1         | Ubuntu 25.04 package          |
| p_r    | (latest)      | CologneChip place-and-route   |
| LiteX  | 2025.12+      | With Migen                    |

## GHDL Yosys Plugin Build

The plugin is installed to user-local paths (no root required):

- `~/.local/share/yosys/plugins/ghdl.so`
- `~/.local/lib/libghdl-5_0_1.so`
- `~/.local/lib/libgnat-14.so`

### Build steps

```bash
# 1. Create a working directory
mkdir -p /tmp/ghdl_plugin_build && cd /tmp/ghdl_plugin_build

# 2. Download the required Ubuntu packages (no sudo needed)
apt-get download libghdl-5-0-1 libghdl-dev libgnat-14

# 3. Extract into a local prefix
for deb in *.deb; do dpkg-deb -x "$deb" local/; done

# 4. Clone the GHDL Yosys plugin source
git clone https://github.com/ghdl/ghdl-yosys-plugin

# 5. Check out the last commit of ghdl.cc compatible with GHDL 5.0.1
#    (newer commits use internal GHDL APIs added after 5.0.1)
cd ghdl-yosys-plugin
git checkout 8c29f2c -- src/ghdl.cc
cd ..

# 6. Compile against the *installed* Yosys headers
#    Adjust the -I path and DYOSYS_VER if your Yosys is elsewhere or a
#    different version.  Use `yosys-config --cxxflags` to discover them.
g++ -c -fPIC -DYOSYS_ENABLE_GHDL \
    -I /usr/local/share/yosys/include \
    -I local/usr/include \
    -D_YOSYS_ -DYOSYS_ENABLE_PLUGINS \
    -DYOSYS_VER=\"0.63\" -DYOSYS_MAJOR=0 -DYOSYS_MINOR=63 \
    -std=c++17 -O2 \
    -DGHDL_VER_HASH="\"8c29f2c\"" \
    ghdl-yosys-plugin/src/ghdl.cc -o ghdl.o

# 7. Link the shared library
mkdir -p ~/.local/lib ~/.local/share/yosys/plugins
g++ -shared -o ~/.local/share/yosys/plugins/ghdl.so ghdl.o \
    local/usr/lib/x86_64-linux-gnu/libghdl-5_0_1.so \
    -Wl,-rpath,"$HOME/.local/lib" \
    -rdynamic -lstdc++ -lm

# 8. Copy the runtime libraries
cp local/usr/lib/x86_64-linux-gnu/libghdl-5_0_1.so ~/.local/lib/
cp local/usr/lib/x86_64-linux-gnu/libgnat-14.so     ~/.local/lib/
```

### Verify

```bash
LD_LIBRARY_PATH=~/.local/lib \
  yosys -p "plugin -i ~/.local/share/yosys/plugins/ghdl.so; \
             ghdl hdl/crc.vhdl -e crc"
```

If this prints the Yosys banner and exits without errors, the plugin is
working.

## Upgrading Yosys

When Yosys is upgraded, the plugin **must be rebuilt** against the new headers.
The ABI changes between Yosys releases (e.g. 0.52 -> 0.63 broke on
`CE_OVER_SRST`).  Re-run steps 6-7 above with updated `-I` path and
`-DYOSYS_VER` values from `yosys-config --cxxflags`.
